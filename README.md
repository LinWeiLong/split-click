# Split Click（v1.1.4）

Chrome Manifest V3 扩展：按住修饰键（默认 Alt）并左键点击链接，在 Chrome 原生 Split View 中打开；也可在**已分屏**时开启「单击直接打开」。

**需要 Chrome ≥ 155**（Tabs Split View API）。仅建议以「加载已解压的扩展程序」方式使用。

## 克隆并加载

```bash
git clone https://github.com/<you>/split-click.git
```

1. 打开 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**（或对已加载项点 **重新加载**）
4. 选择本仓库的**根目录**（含 `manifest.json` 的那一层，不要选子文件夹）

更新代码后请在 `chrome://extensions` **重新加载** 本扩展。

## 行为（v1.1.4）

| 场景 | 操作 | 效果 |
|------|------|------|
| **未分屏** | 普通左键 | **完全原生**跳转（绝不因此新建分屏） |
| **未分屏** | Alt+左键（配置的修饰键） | 新建右侧分屏 |
| **已分屏** + 开启「单击直接打开」 | 普通左键 | 另一侧 / `whenAlreadySplit` |
| **已分屏** + 开启「单击直接打开」 | Alt+左键 | **当前这一侧**打开（拦截 Alt+另存为） |
| **已分屏** + 关闭该选项 | Alt+左键 | 按「已处于分屏时」设置 |
| 任意 | Ctrl/Cmd+点击、中键 | 始终原生 |

> Chrome 原生 Alt+点击是「链接另存为」，不是本页跳转；已分屏且开启单击模式时，扩展会拦截 Alt 并在当前侧打开。

## 设置

扩展详情页 → **扩展程序选项**，或右键工具栏图标 → 选项。

- **已分屏时：单击直接在另一侧打开**（`plainClickOpen`）：仅在已处于 Split View 时简化操作
- **修饰键组合**：默认 Alt
- **已处于分屏时**：另一侧（默认）/ 原地 / 始终新建分屏

## 权限与降级

`tabs`、`storage`、`scripting`；host `http(s)://*/*`。API 失败时退化为右侧新建标签。1.1.2+ 会向已打开标签自动注入内容脚本。

无数据收集、无网络请求。
